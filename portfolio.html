  • 資料流程管理：CDP 資料上傳至 BIG QUERY 後自動化導入 POWER BI

CDP 旅程模組撰寫

資料撈取與邏輯撰寫 會員旅程條件設計 跨團隊協作

負責 CDP (Customer Data Platform) 中的旅程模組開發，運用 SQL 進行資料篩選與邏輯判斷，撰寫可供行銷單位使用的自動化名產出流程。透過 SQL Pipeline 自動產生推送名單，協助行銷建立 EDM、簡訊或 APP 推播旅程。

行銷旅程漏斗轉換率 (Conversion Funnel)

核心技術

  • MS SQL / T-SQL：CTE、ROW_NUMBER、RANK 等函數
  • 子查詢 / 巢狀查詢：複雜資料篩選與計算
  • 資料清洗：格式轉換、缺值處理、資料一致性
  • Pipeline SQL：模組化處理、過濾、彙整、輸出名單
