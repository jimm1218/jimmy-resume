# 靳鈞評 (Jimmy Chin) - 個人履歷與數據專案作品集
**履歷連結：https://jimm1218.github.io/jimmy-resume/**
##
這是一個專為展示**數據分析、BI 開發與資料工程**經歷所設計的個人靜態網站作品集。
全站採用現代化、明亮簡約的風格 (Light Theme)，並具備完整的多頁面架構與良好的互動體驗。

## 🚀 網站功能與特色

- **多頁面導覽 (Multi-page Navigation)**：具備首頁、專業經歷、專案作品集與聯絡我等獨立頁面。
- **高質感明亮 UI**：採用簡約乾淨的白底、淺灰與皇家藍（Royal Blue）配色，呈現專業清晰的視覺體驗。
- **彈窗互動設計 (Modal)**：在作品集頁面中，點擊專案卡片可彈出詳細的技術與經歷說明視窗，不需跳轉頁面。
- **模組化設計**：共用統一的 CSS 樣式表與 JavaScript 腳本，方便後續維護與擴充。

## 📁 專案檔案結構

```text
d:\data\resume\
 ├── index.html        # 個人首頁 (基本介紹與導覽)
 ├── experience.html   # 專業經歷 (詳細工作經驗列表)
 ├── portfolio.html    # 專案作品集 (卡片展示與彈窗詳情)
 ├── contact.html      # 聯絡我 (聯絡資訊與訊息表單)
 ├── README.md         # 專案說明文件
 ├── PROMPT.md         # AI 協作提示詞紀錄
 ├── css/
 │    └── style.css    # 全站共用樣式表 (Light Theme)
 └── js/
      └── script.js    # 互動腳本 (處理 Modal 彈窗等邏輯)
```

## 🛠️ 使用技術

- **HTML5**: 語意化標籤與多頁面結構建置。
- **CSS3**: CSS Variables (變數)、Flexbox/Grid 排版、轉場動畫 (Transitions)、彈窗遮罩設計。
- **JavaScript (Vanilla JS)**: DOM 操作與事件監聽 (Event Listeners)，實作無套件的 Modal 彈窗邏輯。

## 💻 如何運行

這是一個純前端的靜態網站，無需安裝任何依賴套件或伺服器環境。
1. 將此專案下載至本地端。
2. 確保 `css` 與 `js` 資料夾與 HTML 檔案在同一層目錄。
3. 使用任何現代網頁瀏覽器 (Chrome, Edge, Firefox 等) 直接開啟 `index.html` 即可瀏覽完整網站。
