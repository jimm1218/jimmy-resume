會員數據分析
數據報告與分析 報表與簡報製作
負責集團內會員資料概況分析與報告製作，整合來自 SQL 資料庫的會員、交易及行為資料，並利用 POWER BI 進行數據視覺化與分析。透過數據篩選、分群、聚合與指標計算，深入了解會員活躍度、消費行為、忠誠度及偏好品牌，提供管理層與行銷團隊可操作的洞察報告。
核心技術：
  • POWER BI 數據視覺化：設計互動式儀表板與報表
  • 數據分析：會員分群、指標計算、聚合統計、異常值檢測
  • SQL 資料操作：撈取與清理資料，使用聚合函數、JOIN、子查詢
  • 報表自動化：轉化分析結果為高可讀性報表

CDP 旅程模組撰寫
資料撈取與邏輯撰寫 會員旅程條件設計 跨團隊協作
負責 CDP (Customer Data Platform) 中的旅程模組開發，運用 SQL 進行資料篩選與邏輯判斷，撰寫可供行銷單位使用的自動化名單產出流程。透過 SQL Pipeline 自動產生推送名單，協助行銷建立 EDM、簡訊或 APP 推播旅程。
核心技術：
  • MS SQL / T-SQL：CTE、ROW_NUMBER、RANK 等函數
  • 子查詢 / 巢狀查詢：複雜資料篩選與計算
  • 資料清洗：格式轉換、缺值處理、資料一致性
  • Pipeline SQL：模組化處理、過濾、彙整、輸出名單
  • 商業規則轉換：次數、金額、日期、門市、品類篩選邏輯
