# Profile Skill Workspace

This folder stores all new resume-planning and resume-building files for `profile-resume`.

Use the root project files as source material, and place new working files here:

- `source/`: copied or extracted source references when needed.
- `research/`: target job language, market notes, and keyword research.
- `content/`: evidence inventory, open questions, master resume, and tailored resume drafts.
- `prototype/`: layout experiments and draft prototypes.
- `output/`: validated working exports before they are promoted to `../final-resume/`.

Final public or application-ready deliverables can still be placed in `../final-resume/` after validation.
